# 学习工作区（workspace）

一个文件夹，多种语言，点一下就能跑；右边还有 AI 老师随时讲解。

## 怎么运行（只用鼠标）
- 打开任意代码文件，点 **右下角状态栏的 ▶ 运行**：会自动认出是什么语言、自动挑编译器，在底部「终端」里编译并运行。
- 也可以点右上角 **▶**（Code Runner）运行。
- 需要键盘输入的程序（如 Python 的 `input()`），在终端里直接打字回车。
- 断点单步调试：按 **F5**，选对应语言的配置。

## 目录
- `python/`  Python 入门（hello.py）
- `java/`    Java 入门（Hello.java，public 类名要和文件名一致）
- `cpp/`     C++ 入门（hello.cpp）
- `node/`    Node.js 入门（hello.js）
- `web/`     网页入门（index.html）
- `test/`    小练习（sum.c：1+2+…+10）

## 在 VS Code 里问 AI 老师（点按钮，不用记快捷键）
- **讲这个文件**：点右下角「讲这个文件」，或保存后自动讲解，右侧「洄·讲解」从最基础讲一遍。
- **我卡住了**：点「我卡住了」，看看写到哪、哪里错、下一步写什么。
- **直接提问**：点「提问」，在编辑器最右侧打开问答窗口，打字问就行。

## 提示
- 新文件直接放进对应语言目录即可；新建的空文件写了内容后会自动识别语言。
- C/C++ 的「运行」按钮会用 PATH 里的 gcc/g++（或 clang）编译；没有就按提示装 MinGW-w64。
